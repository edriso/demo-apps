# Demo Apps

A collection of web app demos, experiments, and learning projects, with links to their live sites or source code.

Browse [Demo Apps](https://edriso.github.io/demo-apps/).

For the collection of everyday, single-purpose tools, visit [Apps](https://edriso.github.io/apps/). Both collections are linked from the [hub](https://edriso.github.io/hub/).

## Editing and deployment

This is a static `index.html` with no build step. Edit the project cards directly in the page, keeping each project’s existing live or source URL. GitHub Pages publishes the repository root from `main`.

This repository was previously named `apps`; that name now belongs to the everyday apps collection.
